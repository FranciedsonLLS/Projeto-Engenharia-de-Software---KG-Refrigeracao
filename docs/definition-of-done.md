# ✅ Definition of Done (DoD)

Um item só é considerado **Concluído** quando:

## Código
- [ ] Todos os critérios de aceitação foram atendidos.
- [ ] O código está em uma branch e foi integrado via Pull Request.
- [ ] O PR foi revisado e aprovado por pelo menos 1 colega.
- [ ] Não há erros ou avisos novos ao executar o projeto.
- [ ] Testes relevantes foram criados ou atualizados e passam.

## Documentação
- [ ] README ou docs atualizados, se necessário.

## Scrum
- [ ] A issue está fechada e o card em **✅ Concluído**.
- [ ] O PO validou a entrega (na Review ou antes).
