# 📋 Definition of Ready (DoR)

Uma história só entra na Sprint quando:

- [ ] Está escrita no formato **"Como [persona], quero [ação], para [benefício]"**.
- [ ] Tem **critérios de aceitação** claros e testáveis.
- [ ] Está **estimada** em Story Points pelo time.
- [ ] É pequena o suficiente para caber em uma Sprint (até 8 pontos).
- [ ] Dependências identificadas.
- [ ] O time entende o que deve ser feito.
